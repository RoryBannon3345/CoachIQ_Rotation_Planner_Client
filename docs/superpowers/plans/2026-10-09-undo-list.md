# The Undo list — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The record screen's bottom bar has one way to take a tap back: `↶ Undo ▾` opens a sheet listing the game's history newest first, whose top row undoes exactly as Undo does today and whose older count rows offer a `−1` on that cell; the `−` button and minus mode go.

**Architecture:** `src/ui.js` gets a new `undo` sheet (`renderUndoSheet`, `entryText`, `onOpenUndo`, `onUndoMinus`) built on the existing `.screen.sheet-host > .sheet > ul.menu` pattern, and loses `state.minusMode`, the `toggle-minus` action and the `−` button. The top row calls the existing `onUndo()`; a `−1` row calls the existing `tap(…, -1)`. `src/session.js` is **not** touched. `src/styles.css` gets one block of list rules and a two-column bar. Tests: `node --test` units over the fake DOM, Playwright on the built bundle.

**Tech Stack:** Plain JavaScript ES modules, no framework, no dependencies. `node --test` with the fake DOM in `test/helpers/fake-dom.mjs`; Playwright in `e2e/` over the built `dist/`.

**Spec:** `docs/superpowers/specs/2026-10-09-undo-list-design.md` (mockup: `docs/undo-minus-mockup.html`, option E). Background: `docs/superpowers/specs/2026-10-07-minus-cancels-and-typed-score-design.md` §1 defines the minus-cancels-the-open-rally rule this plan keeps.

## Global Constraints

- **Implementers never commit.** No `git commit`, `git push`, `git add`, `git stash`, `git checkout`, no `npm run deploy`, no `buildAndDeploy.bat`. Leave every change in the working tree; the controller manages git after the whole plan is done.
- Implementers never dispatch subagents.
- Plain JS, no new dependencies. Each `import` line in `src/` must stay on ONE line (the build inliner strips single-line imports only).
- `src/session.js` is not modified by any task. The `−1` row uses `tap(session, gameId, n, playerId, stat, side, -1)` exactly as the `−` button did, including its rule that a minus on the cell that opened the open rally cancels that rally.
- Exact bar markup: `<button type="button" class="btn sm undo" data-action="open-undo" ${undoDisabled}>↶ Undo ▾</button>` where `undoDisabled` is `'disabled'` exactly when `game.history.length === 0`, else `''`. The bar grid is `grid-template-columns:1fr 1fr`.
- Exact sheet copy: heading `Take back`; helper `Newest first. The top row undoes it, points and all. A −1 takes one from that count and leaves the points alone.`; pills `↶ Undo` and `−1`. The minus sign everywhere is U+2212 `−`, not a hyphen.
- Row text vocabulary (spec §2): `Grace · Serve In +1`, `Grace · Serve In −1`, letters as ` · Us +1, Them +1`, points as `Us +1` / `Them +1`, re-aligns through the existing `alignText`. A row from another set ends with ` <span class="set">set N</span>`.
- Release: `APP_VERSION` `'4.8.0'`, service worker `CACHE` `'ciq-stats-v17'`, `dist/` rebuilt by `npm run build` only (never `node scripts/build.mjs`).
- Run every browser command (`npm run verify`, `npm run test:browsers`, `npx playwright test …`) from **PowerShell** only; the Bash sandbox kills browsers. Unit tests (`node --test`) run anywhere.

## Review Focus

1. **A point or re-align at the top of the list:** the top row must still say `↶ Undo` and reverse it (a point pops its letter, a re-align restores the shift). Pinned in Task 1 (the `Them +1` top row test).
2. **An older `+1` whose cell is already 0** (an earlier `−1` took it away): the `−1` pill must be disabled, never drive the count negative. Pinned in Task 2 (the `disabled` assertion on the Serve In row).
3. **Picking an older row for the open rally's own cell:** the kept 4.4.0 rule cancels the rally; the toast must say `Open rally cancelled` and the pills must stop being dashed. Pinned in Task 2 (the trade-off test) and Task 3 (e2e).
4. **An entry from another set:** the row must carry `set N` and a `−1` on it must change that set, not the one on screen. Pinned in Task 2 (the two-set test).
5. **Any action closes the sheet before re-render:** `commit()` re-renders, so a sheet left open would show a stale list over the new counts. Pinned in Task 1 and Task 2 (`doesNotMatch /undo-list/` after each action).

```js
const STAT_WORD = { serve: 'Serve', return: 'Return' };
const SIDE_WORD = { in: 'In', out: 'Out' };

/** 'UT' → 'Us +1, Them +1': the letters a tap appended, in the toast's words. */
function lettersLabel(points) {
  return [...points].map((c) => (c === 'U' ? 'Us +1' : 'Them +1')).join(', ');
}

/** One history entry as the Take back sheet reads it (undo-list spec §2). First names. `n` is the
 * set on screen: a row from another set says so, so an Undo that reaches into it is no surprise. */
function entryText(day, h, n) {
  let text;
  if (h.kind === 'point') text = h.winner === 'U' ? 'Us +1' : 'Them +1';
  else if (h.kind === 'align') text = alignText(day, h);
  else text = `${firstName(day, h.playerId)} · ${STAT_WORD[h.stat]} ${SIDE_WORD[h.side]} ${h.delta > 0 ? '+' : '−'}${Math.abs(h.delta)}${h.points ? ` · ${lettersLabel(h.points)}` : ''}`;
  return esc(text) + (h.n !== n ? ` <span class="set">set ${h.n}</span>` : '');
}
```

```js
// ---------------------------------------------------------------------------------------------
// Take back sheet (undo-list spec §2) — the game's history newest first. The top row is Undo.
// ---------------------------------------------------------------------------------------------

function renderUndoSheet() {
  const day = currentDay();
  const game = currentGame();
  if (!game || game.history.length === 0) return '';
  const n = clampedActiveSet(game);
  const rows = game.history.slice().reverse().map((h, i) => {
    const text = entryText(day, h, n);
    if (i === 0) return `<li><button type="button" data-action="undo"><span class="what">${text}</span><span class="pill">↶ Undo</span></button></li>`;
    return `<li class="muted-line context"><span>${text}</span></li>`;
  }).join('');
  // Backdrop closes, like the Games and Menu sheets: no Cancel button.
  return `
<div class="screen sheet-host" data-action="close-sheet">
  <div class="sheet">
    <h3>Take back</h3>
    <p class="helper">Newest first. The top row undoes it, points and all. A −1 takes one from that count and leaves the points alone.</p>
    <ul class="menu undo-list">${rows}</ul>
  </div>
</div>`;
}
```
