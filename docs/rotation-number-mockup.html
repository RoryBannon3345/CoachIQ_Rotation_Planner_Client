Rotation number — five placements

The record screen shows the rotation the phone thinks we're in. It is worked out from serve-first, the rally log and any re-align, by the same count that drives the server highlight: rotation = (side-outs we've won + re-align shift) mod 6, plus 1. No roster plan is needed for the number, so it shows on an older roster too. All five options also make the Undo button say plain ↶ Undo. Every frame below is the same moment: set 1, we're serving at 14–11, rotation 3, Hailey serving.

Recommendation: C, the pill in the Player column header.
  • It sits directly above the rows, where the coach's eyes already are, and lines up with the highlighted row's accent bar, so "rotation 3, Hailey" reads as one thing.
  • It costs nothing: no height (the density guard measures the column header, so the pill is sized to fit the line it is on), no width taken from the Us/Them pills, and no extra cell in the bottom bar. It touches one line of HTML and one CSS rule.
  • It shows on an older roster with no plan, which D cannot.
  • Its only cost is size: the pill is small. If a bigger number matters more than keeping the score pills full width, A is the runner-up.
Why not the others: A narrows the two buttons tapped every rally. B is the easiest to miss and competes with long opponent names. D disappears without a plan. E puts the number farthest from the rows and adds a fourth cell to a bar that fits three.

A · Chip in the set bar between the set tabs and the score

A blue tile the same height as the score pills. The pills give up about 46px of width, so Us/Them get a little narrower on an iPhone SE. No height is added, so the 12-row density guard is safe. The most visible of the five.

B · In the title line next to the game and date

Costs nothing in layout. The title line already truncates long opponent names, so a long name plus the number may show an ellipsis. The easiest to miss mid-rally, because the eye is on the rows.

C · In the Player column header Recommendeda pill beside "PLAYER"

Sits right above the rows where the coach is already looking, and the header has unused width on the left. The header text is small, so the number has to stay a short "R3" pill. Zero height change.

D · Badge on the highlighted row travels with the server

The number sits next to the server's name, so "who" and "where" read together. Limitation: with no plan (older roster) there is no highlighted row, so there is nowhere to put the number and it would not show. Long names truncate a little earlier to make room for the badge.

E · Tile in the bottom bar next to the minus button

Possible only because Undo is becoming plain "↶ Undo" and no longer needs the width. A read-only tile beside the "−" button; it is not a button. Keeps the set bar and rows exactly as they are today.

What all five share

SituationWhat shows
We serveThe rotation we are in. The highlighted row is its server.
They serveStill the rotation we are standing in. The highlighted row is our next server, who is one rotation ahead, because we rotate only when we win the ball back.
Coach taps Serve for someone else (re-align)The number moves with the re-align, and Undo moves it back.
Older roster, no planThe number still shows (except in option D), from serve-first and the rally log alone.
Train set (plan longer than 6)Nothing. The plan walks a line of spots, not rotations 1 to 6.
Serve-first unanswered, or a typed scoreNothing, as with the highlight.
