CoachIQ Rotation Planner — Day Model (v2) Design Preview

Today the app opens one game per pasted roster: a coach pastes a fresh roster for every match. This preview shows the day model instead: one whole tournament day per pasted roster. The coach pastes the day's player directory once in the morning, records up to eight games against that shared roster without pasting anything between matches in the gym, then exports one stats payload covering every game at night. The six panels below are static, non-interactive frames for review only — nothing here is shipped code or imported by the app.

1. Paste screen

Today this opens a single game. The new version opens the whole day's player directory once, before any games exist yet.
